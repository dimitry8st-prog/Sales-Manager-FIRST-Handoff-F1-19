3. Реализация

Добавлен модуль sales_handoff_intent.py с функцией:

build_handoff_intent(context, recipient, interest)

Модуль проверяет:
- точный набор полей recipient и interest;
- версии схем, типы и допустимые идентификаторы;
- допустимое значение решения об интересе;
- соответствие клиента, кампании и лида;
- контекст через принятую assemble_handoff_context
  из неизменённого sales_first_handoff.py.

При INTEREST возвращает PREPARED с подготовленным контекстом.
При QUESTION или UNCERTAIN возвращает HOLD
с кодом INTEREST_NOT_CONFIRMED.

Подготовленный контекст имеет delivery_status=NOT_DISPATCHED.
Ошибки входа: HandoffIntentError с публичным кодом.
Ошибки принятого компонента F1-09 передаются вызывающему коду.

Порядок проверки ошибок:
INVALID_INPUT → SCOPE_MISMATCH → ошибки F1-09.

Модуль не отправляет уведомления, не создаёт задачи в БД
и не записывает действия в журнал.
Входные данные не изменяются; возвращаемый контекст
не должен предоставлять возможность изменить исходные данные.
